# jewels.json.gz and the timeless jewel tables

`jewels.json.gz` (built by `scripts/build-jewels.js`) holds the passive tree from Grinding Gear
Games' [skilltree-export](https://github.com/grindinggear/skilltree-export) and, from
[Path of Building Community](https://github.com/PathOfBuildingCommunity/PathOfBuilding), the
timeless jewel passives, the order of the timeless jewel tables and the cluster jewel notables.
The timeless jewel tables themselves are downloaded from Path of Building on first use
(`src/core/jewels/tables.js`). Game data (c) Grinding Gear Games. Path of Building Community is
