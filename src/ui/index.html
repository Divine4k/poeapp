            Settings

            Reading your inventory

            GGG's rules allow one screen read, and one action sent to the game, per manual key press. Reading on your inventory key and the single Ctrl+C on the check key stay within that. Checking by itself reads without a key press, so it breaks that rule and is your own risk. Without it, press your inventory key once after arriving in the hideout, before you stash.

              Shared item list

              Everyone gets the shared list without a token. Uploading needs a fine-grained GitHub token limited to the poeapp repository with "Contents: read and write". It is stored encrypted on this PC and only ever sent to GitHub. Reports go to the same public repository; they hold the inventory slots as the app saw them, nothing else from your screen.

              Map mods my build cannot run

              This app reads the game log, the clipboard and the screen. The only thing it ever sends to the game is one Ctrl+C when you press the check key, if that option is on. It never touches game memory or files. It is not affiliated with or endorsed by Grinding Gear Games. Prices come from poe.ninja.
